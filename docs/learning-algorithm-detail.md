# 학습 알고리즘 설계: ASR (Adaptive Successive Relearning) — 상세

> 📄 처음이라면 **[개요 문서(learning-algorithm-overview.md)](./learning-algorithm-overview.md)** 를 먼저 보세요(mermaid로 한눈에). 이 문서는 모든 규칙·수치·근거를 담은 상세본입니다.
> 📚 이론 근거는 **[learning-science-research.md](./learning-science-research.md)**.

> "코드"가 아니라 **학습자가 거치는 순서·규칙**으로 본 알고리즘.
> 리서치에서 가장 효과가 큰 4가지 — **인출(retrieval) · 분산(spacing) · 성공적 재학습(successive relearning) · 사전테스트(pretesting)** — 를 하나의 루프로 합치고, **시험 데드라인에 적응**시킨 것.

핵심 한 줄: **"매 세션 정답 1회까지 떠올리되, 그 세션을 여러 날에 걸쳐 분산하고, 간격은 시험일에 맞춰 자동 조절한다."**

---

## ★ 대명제 (이 알고리즘이 반드시 지켜야 할 것)

**입력은 단 두 개:** ① **학습 내용**(구조화된 카드들), ② **시험 날짜**.
이 둘만으로 **매일의 학습 플랜**(오늘 무엇을 몇 개, 어떤 강도로)이 생성되어야 한다.

**전제 — 학습자는 계획대로 안 한다:**
- 어떤 날은 **미룬다/건너뛴다**(누적 밀림 발생).
- 어떤 날은 **유난히 많이 한다**(앞당겨 몰아치기).

→ **알고리즘은 이 변동을 매일 흡수하며 학습량·강도를 유동적으로 재조정**해야 한다.
이것이 충족의 1차 기준이다. (세부 학습원리보다 **이 적응성이 먼저**다.)

설계 귀결 → **플랜은 미리 고정해 굽지 않는다(no frozen 7-day plan).** 유일한 영속 상태는 `카드별 S/D/단계 + 시험일`뿐이고, **매 세션 시작 시 현재 상태에서 그날 플랜을 새로 생성**한다. 미룸·몰아치기가 자동으로 흡수되는 이유가 바로 이것. (적합성 검토와 적응 컨트롤러는 **§5.5** 참조.)

## 0. 왜 이 조합인가 (설계 원칙)

| 원칙 | 근거 | 알고리즘에 박힌 방식 |
|---|---|---|
| 떠올리기가 학습이다 | 테스트 효과 (Dunlosky 최상위) | 모든 노출이 "인출 시도" |
| 나눠야 남는다 | Cepeda 분산학습 | 같은 카드를 여러 날 재등장 |
| 세션마다 한 번은 맞혀라 | Successive Relearning → 시험 1등급↑ | 세션 내 "정답 1회" 졸업 기준 |
| 먼저 틀려봐라 | Pretesting / errorful generation | 첫 노출은 "찍기 → 정답 공개" |
| 섞어야 변별된다 | Interleaving (63% vs 20%) | 혼동쌍·유형 교차 배치 |
| 체감≠효과 | Bjork 바람직한 어려움 | 사용자 "안다" 자기판단 불신, 데이터로 판정 |

> **⚠️ 목적함수를 분명히 하자 (단기 시험의 핵심).**
> Anki/FSRS 같은 일반 SRS의 목표는 *"장기 보유를 최소 복습으로"* 다 — FSRS의 간판 문구 "복습 20~30% 절감"은 이 목표에서의 효율이다.
> 그러나 **시험 벼락치기의 목적함수는 다르다**: *"제한된 며칠 안에 **시험 당일** 회상률을 최대화"*. 이 목표에선 복습을 **줄이는 게 아니라 늘려야** 한다.
> → 그래서 이 알고리즘은 평소엔 SRS식 "잊기 직전 복습"을 쓰되, 시험이 가까우면 **목표 보유율을 올리고 간격을 데드라인으로 압축**해(§5) 의도적으로 복습을 더 촘촘히 한다. "복습이 적을수록 좋다"는 FSRS 프레임을 단기 시험에 그대로 적용하면 틀린다.

## 1. 카드 상태 모델 (학습적 의미만)

각 카드는 세 숫자로 그 학습자에게서의 상태를 가진다 (FSRS의 3요소를 학습 언어로):

- **안정도 S** = "지금 안 보면 며칠 버티나" (망각까지의 일수). 성공 인출마다 늘고, 실패하면 준다.
- **난이도 D** = "이 카드가 이 사람에게 본질적으로 얼마나 어려운가". 자주 틀리면 오른다.
- **인출확률 R(t)** = "지금 떠올릴 확률". 시간이 지나며 멱법칙으로 감쇠.
  - 직관식: `R ≈ (1 + t / (c·S))^(-1)` — t는 마지막 복습 후 경과일.
  - **복습 시점 규칙(단일 스케줄링 원리):** R 이 **목표 보유율(target)**까지 떨어졌을 때 재등장 = "잊기 직전에 떠올린다"(desirable difficulty).
  - 목표 보유율 target: 평소 **0.90**, 시험 1주 전부터 **0.93~0.95**로 상향(시험일에 R 최대가 되도록).

> **간격은 오직 S에서 나온다 — 별도 ease 배수는 없다.**
> R = target 이 되는 시점을 위 식에서 풀면 **다음 간격 = (상수)·S**. 즉 간격은 안정도 S에 정비례하고, S가 성공 인출마다 커지므로 간격이 자연히 늘어난다. (SuperMemo/SM-2처럼 "이전 간격 × ease factor"를 따로 두면 같은 양을 이중 계산하는 모순 — 그래서 쓰지 않는다. FSRS가 ease 방식을 버린 이유와 동일.)
> 곱 상수들(S 성장률 등)은 **데이터로 적합(fit)되는 값**이지 이론에서 떨어지는 상수가 아니다 — 이게 FSRS 옵티마이저가 하는 일. 본 문서의 숫자는 모두 **예시(illustrative)**.

> 학습자에겐 이 숫자를 "기억 강도 ▓▓▓░ 78%"처럼 보여줘 동기 보상(체감 난이도 보정).

## 2. 채점 척도 (인출 1회마다)

등급은 **간격을 직접 정하지 않는다.** 등급은 **안정도 S의 변화량**을 정하고, 간격은 그 S에서 자동으로 나온다(§4).

| 등급 | 의미 | S(안정도) 변화 |
|---|---|---|
| ✗ **Again** | 못 떠올림 / 틀림 | **S 큰 폭 하락**(→ 짧은 간격), D 상향, 세션 내 재큐 |
| ◑ **Hard** | 떠올렸지만 한참·불확실 | S 소폭 상승 |
| ○ **Good** | 정확히 떠올림 | S 표준 상승 |
| ◎ **Easy** | 즉시·확신 | S 큰 폭 상승 |

핵심: **떨어진 R에서 겨우 떠올렸을수록(=어렵게 인출) S 상승폭이 크다**(desirable difficulty). 너무 쉽게(높은 R에서) 맞히면 정보 이득이 작아 덜 오른다.
자기보고 등급이지만 mcq/단답은 **자동 채점**으로 ✗/○를 객관 확정(자기판단 착각 방지).

## 3. 카드 한 장의 생애주기 (7단계)

```
[0 미학습] → [1 사전테스트] → [2 인코딩] → [3 첫 인출]
              → [4 분산 재인출] ⟲(여러 날) → [5 숙달] → [6 유지]
```

- **0 미학습(New):** 아직 안 본 카드.
- **1 사전테스트(Pretest):** 배우기 전에 **찍어보게** 한다. 틀려도 됨 → 즉시 정답·해설. (틀린 추측이 이후 인코딩을 강화)
- **2 인코딩(Encode):** 개념 본문 + **"왜 그런지 한 문장 자기설명"** 요구(elaboration). 단순 읽기로 끝내지 않음.
- **3 첫 인출(Acquire):** **같은 세션 안에서** cloze→단답으로 **정답 1회**까지 떠올리면 그 세션 졸업. 실패하면 세션 내 3~5장 뒤 재등장(세션 내에서도 살짝 spacing).
- **4 분산 재인출(Consolidate) ⟲:** 다른 날들에 R이 target까지 떨어질 때 재등장. **매 세션 정답 1회까지** = successive relearning의 본체.
- **5 숙달(Mastered):** "졸업 조건"(§6) 충족 → 저빈도 유지로 강등.
- **6 유지(Maintain):** 시험 전까지 가끔만 점검. 틀리면 4단계로 복귀.

## 4. 간격은 어떻게 나오나 (S에서 도출, ease 없음)

**별도의 간격 공식이 없다.** 절차는 단 둘:
1. 인출 등급 → **S를 갱신**(§2).
2. **다음 복습일 = R이 target까지 떨어지는 날** = `다음 간격 ≈ (상수)·S`.

즉 간격을 "키우는" 게 아니라, **S가 커지니 R이 천천히 떨어지고, 그래서 간격이 자연히 길어진다.** 등급은 S에만 작용한다.

- **첫 성공(3단계 통과):** S가 작은 초기값 → 다음 간격이 짧다(대략 하루 안팎).
- **연속 성공:** S가 단계적으로 커지며 간격이 점점 벌어진다(대략 1.5~2.5배씩 — 이 성장률은 **데이터로 적합되는 예시값**, 고정 상수 아님).
- **실패(Again):** S가 크게 떨어져 간격이 짧게 리셋. 세션 내 3~5장 뒤 재등장 → 통과해도 그날 졸업만, 다음 간격은 짧게.
- **"저간격 지옥" 회피:** 반복 실패 카드는 D를 올려 S 회복을 느리게 하되, **세션 내 무한 반복은 금지**(massing 회피 — 반드시 다른 카드를 사이에 끼워 spacing).

> 위 자연 성장 간격을 그대로 두면 "장기 보유 최소복습" 모드. 시험이 있으면 이 간격을 **데드라인으로 누른다**(§5).

## 5. 시험 데드라인 적응 (이게 단기 고득점의 핵심)

표준 SRS는 "장기 보유"가 목표라 간격이 길어 **시험 전에 복습이 안 잡히는** 함정이 있다. 그래서 deadline로 역산해 압축한다.

입력: 시험일 D, 오늘 t₀, 남은 일수 **Δ = D − t₀**.
목표: 시험일까지 카드당 **성공 세션 ≥ N_min (기본 3)** + **R(D) ≥ target**.

- **간격 cap:**
  `I_적용 = min(I_자연성장, max(1, floor(남은일수 / 남은필요세션)))`
  → 카드가 시험 전 균등하게 N_min번 떠오르도록 강제.
- **압축 모드 (Δ < 7):** 하루 다회 세션 허용. 단, 같은 카드 같은 날 재등장은 **다른 카드들을 사이에 충분히 끼워** spacing 유지(절대 연속 반복=벼락 암송 금지).
  - 최적 간격 ≈ 보유기간의 10~20%이므로 D-3 같은 초단기엔 이론상 **하루 미만 간격**이 맞다 → 압축 모드에선 같은 날 재등장으로 이를 근사한다. (평소 regime의 "최소 1일 간격"은 일상 사용 단순화일 뿐, 단기 시험엔 적용 안 함.)
- **목표 보유율 상향:** 시험 1주 전부터 target 0.90 → 0.95 → 복습이 더 촘촘.
- **마지막 날:** 신규 0. **약점 카드(저 S, 오답 이력)** + application/mcq 집중 재인출.

균등 분산 로드밸런싱: `오늘 신규 한도 = ceil(미학습수 / 남은일수 × 1.2)`. 막판 몰림 방지.

## 5.5 대명제 적합성 검토 + 적응형 일일 컨트롤러

### (A) 적합성 감사 — 현재 알고리즘이 대명제를 만족하는가?

| 대명제 요구 | 기존 §1~§5 커버 | 판정 | 보강(아래 컨트롤러) |
|---|---|---|---|
| 입력 = 내용 + 시험날짜만 | §5가 이미 그것만 사용 | ✅ | 최상단 명문화 |
| 매일 플랜이 생성 | §7 세션구성 + `rebalance_tomorrow` | 🟡 부분 | **"매일 상태에서 재생성"**을 정식 규칙으로 |
| **미룸/건너뜀(밀림) 흡수** | overdue는 자연 발생하나 **backlog 처리 정책 없음** | ❌ 빠짐 | **백로그 우선순위·분산 정책** |
| **몰아서 많이 함** | "내일 부하 축소" 한 줄뿐 | 🟡 부분 | **앞당김 가치순 + 한계효용 정지 → 신규로 유도** |
| 학습량·**강도** 유동 조절 | target 상향, 신규 cap 산발적 | 🟡 부분 | **3-상태 컨트롤러로 통합** |
| 분량 ≫ 남은 시간(불가능) | 없음 | ❌ 빠짐 | **실현가능성 점검 + 트리아지** |

→ 결론: 골격(인출·분산·데드라인 cap)은 맞지만, **밀림 흡수 / 몰아치기 흡수 / 실현가능성**이 빠져 있다. 아래 컨트롤러가 이를 메운다.

### (B) 적응형 일일 컨트롤러 — 매 세션 시작 시 실행

영속 상태는 `카드별 S/D/단계 + 시험일`뿐. 매번 **현재 상태에서 새로 계산**한다(고정 플랜 없음).

**1) 지평 재계산:** 남은 일수 `Δ = 시험일 − 오늘`.

**2) 작업 풀 구성 + 우선순위 점수** (자원이 모자랄 때 무엇부터 할지):
- 구성원: ① **연체 복습**(과거에 due였는데 밀린 것), ② **오늘 due 복습**, ③ **신규 카드**.
- 우선순위 = **위험도 × 시험중요도**:
  - **위험도:** R이 낮을수록 / 더 오래 연체될수록 ↑ (완전 망각 직전 카드 = 최우선). 가장 약한 카드 먼저.
  - **시험중요도:** 시험 전 남은 성공 기회가 적은 카드 ↑ (지금 안 하면 N_min 못 채움).
  - 이미 숙달 근접 카드는 ↓. → 순효과: **약하고·연체되고·시험임박한 카드 우선.**

**3) 일일 용량(capacity):** 학습자의 그날 가용 시간/분량. 컨트롤러는 두 수치를 비교:
- **필요 처리량** `required_today = 연체 + 오늘 due + 신규할당`
- **실제 용량** `capacity_today` (기본값 = 평소 페이스, 학습자가 그날 늘리거나 줄임)

**4) 신규 투입(intake)의 데드라인 가드:** 신규 카드는 시험 전 **N_min번 분산 성공**할 시간이 있어야 한다.
- `신규 도입 마감일 = 시험일 − (N_min회 분산에 필요한 최소 일수)`. 그 이후엔 **신규 0**, 복습·다지기만.
- 신규 할당 = `ceil(남은신규 / 신규가능일수)`, 단 뒤처지면 상향·앞서면 하향(아래 상태기계).
- **⚠️ 신규 중단(BEHIND-과부하) vs 도입 마감일 충돌:** BEHIND로 신규를 미루다 **도입 마감일을 넘기면**, 그 신규 카드는 N_min 분산을 못 채운다 = **사실상 누락(트리아지)**. 이건 공짜가 아니므로 **§5.5-8 경로로 사용자에게 "이 범위는 못 본다"고 고지**해야 한다(조용한 누락 금지). 충돌 시 우선순위: **이미 학습 중인 카드의 숙달 > 새 범위 추가** (반쯤 익힌 걸 버리는 게 더 손해).

**5) 스케줄 건강 3-상태 → 학습량·강도 자동 조절:**

> **주의: "BEHIND"는 원인이 둘이고 처방이 정반대다.** 강도(target) 노브를 원인에 따라 반대로 돌려야 한다 — 뭉뚱그리면 구멍을 더 판다.

| 상태 | 감지 | 학습량 조절 | 강도(target·문항) 조절 |
|---|---|---|---|
| 🟢 **ON-TRACK** | 백로그≈0, 신규 페이스 정상 | 평소 용량 | target 0.90 |
| 🔴 **BEHIND-과부하**<br>(카드가 너무 많음) | **백로그 > 용량** | ① **신규 일시중단**(백로그 해소까지) ② 일일 용량 상향 권고 ③ 백로그 남은 날 분산 | **target 유지/하향**(↑하면 복습이 더 늘어 구멍 심화) |
| 🔴 **BEHIND-숙달**<br>(백로그 작은데 자꾸 실패) | 백로그 작음 + **lapse 빈발** | 신규는 유지, **약점 카드 재인출 추가** | **target 상향 + 약점 집중 + 심화 유형** |
| 🔵 **AHEAD (몰아서 함)** | 오늘 큐 소진 + 더 하려 함 | ① **신규 앞당김 우선**(싸고 가치 큼) ② 미래 복습 앞당김은 **가치순·한계효용까지만**(단, 압축윈도 예외 ↓) | 더 어려운 유형(application/mcq)로 |

> **왜 반대인가:** target↑ = 복습 임계를 낮춤 → 카드가 더 일찍 due → **복습량 증가**. 카드가 넘쳐 밀린(과부하) 상황에서 복습을 더 늘리면 악화. 반면 카드가 자꾸 새는(숙달부족) 상황은 복습이 **모자란** 것이니 target↑이 맞다.

**6) "밀림(미룸)" 흡수 — 핵심 ①:**
- 복귀 시 연체분을 **위험도순 재정렬**(가장 많이 감쇠한 것 = 망각 직전 = 최우선).
- 백로그가 오늘 용량을 넘으면 **남은 일수에 분산**해 흡수(하루에 몰아 처리=massing이라 보유율 낮음 → 피함). **단 시험이 임박하면** 분산 여유가 없으므로 더 빨리 비운다.
- 신규 할당은 **남은 일수 축소분만큼 자동 압축**. 압축해도 안 되면 → **트리아지(7)**.
- 한 번의 큰 밀림이 완주를 불가능하게 만들면 → 즉시 사용자에게 **강도 상향 또는 범위 축소** 제시.

**7) "몰아서 많이 함" 흡수 — 핵심 ②:**
- 학습자가 더 하길 원하면, **앞당김의 가치 = 기대 S 증가량**으로 정렬해 서비스.
  - **평소(장기보유) 모드:** 미래 복습을 미리 하면 **R이 아직 높아 S 증가가 작다**(정보이득 적음). → **한계가치가 임계 미만이면 중단**하고, 남는 의욕은 **신규 카드/더 깊은 문항유형**으로 돌린다(무의미한 massing 방지).
  - **압축/상향-target 윈도(시험 임박) 예외:** 목적함수가 "시험당일 회상 최대화"로 뒤집히므로 **고-R 복습도 S를 올려 시험당일 R을 끌어올린다** → 이때는 **컷오프를 낮추거나 끈다.** 게다가 이 시기엔 신규 투입이 닫혀(§5.5-4) "신규로 돌리기"가 불가능하므로, AHEAD의 주 배출구는 **더 깊은 문항유형(application/mcq)**과 **약점 카드 추가 인출**이다.
- 오늘 많이 했으면 **내일 이후 용량을 자동 하향**해 평탄화(번아웃·다음날 공백 방지).

**8) 실현가능성 점검 + 트리아지 — 핵심 ③ (정직성):**
- 매 재계획 시 `총 필요 인출수`(미숙달 카드 × 남은 필요세션)와 `남은 용량(용량 × 남은일수)`을 비교.
  - (주의) 이 슬롯 계산은 "서로 다른 날" 분산 제약은 못 본다 — `남은일수 < N_min`이면 슬롯이 충분해도 분산이 불가. 이 경우 **§6의 짧은-시험 졸업 완화**가 반드시 함께 적용되어야 "feasible" 판정이 거짓이 되지 않는다.
- **수요 > 공급 = 불가능** → 트리아지 발동:
  - 우선순위 낮은(덜 중요·이미 약하지 않은) 카드는 **N_min을 낮추거나 범위에서 제외**,
  - **무엇을 줄이는지 사용자에게 명시**(조용히 누락 = "다 봤다" 착각 유발 → 금지).
  - 동시에 **일일 용량 상향**을 권고. 사용자가 받으면 트리아지 완화.

### (C) 한 줄 요약
**플랜은 매일 폐기·재생성된다.** 미룸 → 백로그를 위험도순으로 남은 날에 분산(임박하면 가속). 몰아치기 → 신규·심화로 흡수하되 무가치한 조기복습은 차단. 분량 초과 → 트리아지를 **드러내놓고** 수행. 강도(target·문항난이도·분량)는 **ON-TRACK/BEHIND/AHEAD** 상태기계가 자동 조절.

## 6. 졸업(숙달) 조건 — "이 카드 시험 준비 완료"

다음을 **모두** 만족하면 5단계(숙달)로:
1. **서로 다른 3일 이상**에서 성공 인출(✗ 아닌 등급) — successive relearning 충족,
2. 마지막 등급 ≥ Good,
3. 예측 **R(시험일) ≥ target**.

→ 이후엔 유지(저빈도)만. 유지 중 ✗ 나오면 즉시 4단계로 복귀.

- **짧은 시험(남은 일수 < N_min)일 때:** "다른 3일" 조건은 달성 불가하므로 완화 — **가용 일수만큼 서로 다른 날 성공**을 목표로 하고, 졸업 판정은 조건①을 빼고 **R(시험일) ≥ target** 만으로 한다(압축 모드와 정합).

(연구 주의점: "첫날 3연속 정답"으로 과하게 다지는 건 3세션 분산을 거치면 이점이 사라짐 → **첫날 과적합 대신 날짜 분산에 투자**.)

## 7. 세션 구성 알고리즘 (한 번의 학습 세션)

1. **due 수집:** R ≤ target 인 복습 카드.
2. **신규 추가:** 오늘 신규 한도만큼 0단계 카드.
3. **비율:** 복습:신규 ≈ **70:30** (시험 가까울수록 복습↑, 막판 100:0).
4. **순서 = interleaving:**
   - 같은 개념/같은 유형 **연속 금지**.
   - **혼동쌍(confusable)** 은 한 세션에 함께(단, 연속은 아니고 사이를 둠) → 변별 훈련.
   - ✗ 카드는 즉시 말고 **3~5장 뒤** 재등장.
5. **길이:** **15~25분** 권장(분산 > 몰아치기). 넘으면 분할해 다른 시간대로.
6. **종료 후:** 내일 예상 부하 미리보기 → 과부하면 신규 한도 자동 축소.

## 8. 의사 흐름 (요약 pseudocode, 자연어)

```
세션 시작(= 매번 상태에서 재생성, 고정 플랜 없음):
  Δ ← 시험일 − 오늘                              # §5.5-1 지평 재계산
  pool ← 연체복습 ∪ 오늘due ∪ 신규               # §5.5-2 작업 풀
  점수매김(pool, 우선순위 = 위험도 × 시험중요도)    # 약하고·연체되고·임박 카드 ↑

  state ← 건강판정(백로그, 신규페이스, Δ)          # §5.5-5: ON_TRACK / BEHIND / AHEAD
  if 불가능(총필요인출 > 남은용량): 트리아지+사용자고지  # §5.5-8
  신규할당 ← intake(Δ, state)                     # BEHIND면 0, 데드라인 가드 적용 §5.5-4
  capacity ← 오늘_가용량(학습자가 늘/줄임)          # 미룸·몰아치기의 '실제' 신호

  queue ← interleave(우선순위순 pool, 신규할당)     # 유형·혼동쌍·연속금지

  while queue 비지 않음 and 처리량 < capacity:
    card ← queue.pop()
    if card.단계 == 미학습: pretest → encode → grade ← retrieve   # 첫 인출
    else:                  grade ← retrieve; show_feedback        # 복습+즉시피드백
    update_stability(card, grade)                # §2: 등급 → S,D (ease 없음)
    card.due ← 오늘 + cap_to_exam(interval_for_target(card.S))    # §4 + §5
    if grade == Again: queue.insert(card, 현재+3~5)               # 세션 내 spacing
    if 졸업조건(card, Δ): card.단계 ← 숙달          # §6 (짧은 시험이면 완화)

  if state == AHEAD and 학습자_더원함:            # §5.5-7 몰아치기 흡수
    serve(신규 먼저 → 미래복습은 기대S증가 순, 한계가치<임계면 중단)
  rebalance(이후_일자_용량)                        # 오늘 과/소 수행분을 평탄화
```
> 미룸은 다음 세션의 `pool`에 **연체복습**으로 자동 유입되어 위험도순 처리됨 — 별도 "밀린 플랜 복구" 로직이 필요 없다(상태에서 재생성하므로).

## 9. 한눈 요약

- **엔진:** 적응형 성공적 재학습(ASR) = 인출 × 분산 × "세션당 정답 1회" × 데드라인 적응.
- **첫 노출:** 사전테스트(찍기) → 개념 → 자기설명.
- **복습 시점:** "잊기 직전"(R=target)에 재등장, target은 시험 임박 시 상향.
- **간격:** 등급 → 안정도 S 갱신 → 간격 = (상수)·S 로 자동 도출(별도 ease 없음). 단 **시험일로 cap**.
- **목적함수:** 평소는 "장기 보유 최소복습", 시험 임박엔 "시험당일 회상 최대화"로 전환(복습을 더 늘림).
- **졸업:** 다른 3일 이상 성공 + R(시험일)≥target.
- **세션:** 짧게(15~25분), 교차 출제, 약점 우선, 즉시 피드백.
- **적응성(대명제):** 입력은 내용+시험날짜뿐 → 플랜은 매일 재생성. **미룸=백로그 위험도순 분산, 몰아치기=신규·심화로 흡수(무가치 조기복습 차단), 분량초과=드러낸 트리아지**. 강도는 ON-TRACK/BEHIND/AHEAD 상태기계가 자동 조절(§5.5).
- **신념:** 사용자의 "안다"를 믿지 말고 인출 데이터로 판정.
